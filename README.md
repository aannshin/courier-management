\# Courier Management System



A dynamic Flask-based courier management web application for managing shipments, tracking deliveries, and providing separate access for customers, delivery agents, and administrators.



\## Features



\- User registration and login

\- Role-based access for customers, delivery agents, and administrators

\- Shipment creation and management

\- Shipment tracking using tracking ID

\- Delivery status and location updates

\- Admin dashboard

\- JSON API for shipment data

\- Health-check endpoint

\- Server-generated commit ID displayed on the website



\## Technologies Used



\- Python

\- Flask

\- SQLite

\- HTML

\- CSS

\- Jinja2

\- pytest

\- flake8

\- Docker

\- Git \& GitHub

\- GitHub Actions

\- Render
